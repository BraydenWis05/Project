# Side Quest — Product Requirements Document

See the full PRD as provided in the originating task. Key sections summarized below for quick reference; the prototype in `/app` implements the MVP "Must Have" loop.

- **Vision:** Make everyday life feel like a game worth playing.
- **Core loop:** Open → start solo or invite friends → random mission → do it in the real world → submit → see everyone's take → react/vote → go again.
- **Navigation:** Home, Explore, Activity, Profile.
- **Categories:** Observation, Photography, Creativity, Social, Exploration, Chaos.
- **Group types:** Everyone's Playing, Team Mission, Friendly Competition (2–8 players).
- **Reactions:** Best one · Absolutely unhinged · Surprisingly impressive · I hate how good this is · LOL.
- **Deadlines:** None, 30 minutes, 24 hours.
- **Safety:** No precise location, no trespassing, no photographing strangers without consent, no dangerous stunts; report & block; private profiles.
- **North Star:** Completed quests per weekly active user.
- **Not in MVP:** Public feed, DMs, IAP, complex leaderboards, live location, AR.
